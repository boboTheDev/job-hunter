## Verification note

The `buyya.com` TLS certificate did not match the requested hostname. Those downloads therefore used the author-provided HTTP URLs with certificate verification bypassed after redirect. Content was accepted only after PDF-signature and parser checks above. The hashes make any later substitution detectable.

The PDF extraction/rendering environment did not include Poppler, so validation was structural and textual rather than a page-image review. The original PDFs are preserved unchanged.

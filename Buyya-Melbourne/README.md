- `docs/`: the original instructions and older CLOUDS admission guide.

- `sources/`: the live CLOUDS admission text plus mechanically extracted PDF text for local searching. See [`sources/README.md`](sources/README.md). These are working files, not authoritative substitutes for the original sources.

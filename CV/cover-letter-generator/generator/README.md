# Cover Letter Generator

One-page HTML cover letter generator for Minn Bo Bo.

## Use

Open `index.html` in a browser, paste a job description, add company details, then click `Generate`.

The generated letter can be edited directly in the preview. Use `Copy`, `Download`, or `Print` when it is ready.

## Core Voice File

`.writing-instruction.md` contains the writing rules distilled from `../my-writing-samples/`.

Future generator logic should follow that file when creating or revising cover letters.
